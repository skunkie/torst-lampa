# Плагин Torst для Lampa

[English](README.md) | [Русский](README.ru.md)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.9-blue?logo=typescript)](https://www.typescriptlang.org/)
[![Lampa](https://img.shields.io/badge/Lampa-Plugin-purple)](https://github.com/yumata/lampa)

Плагин [Torst](https://github.com/torrplay/torst) для медиаплеера [Lampa](https://github.com/yumata/lampa). Воспроизводит торренты через Torst на Android TV, Smart TV (Tizen, WebOS) и в браузерах.

Torst еще не выпущен и активно разрабатывается. Плагин рассчитан на текущий API; при его изменении обновляйте инстанс и плагин вместе.

Для временного просмотра плагин создает торрент с `retention: temporary` в оперативной памяти, без метаданных библиотеки и постера. Torst удаляет его, когда просмотр прекращен и истекло время ожидания. Плагин не отправляет запросы удаления после просмотра. Действие «Сохранить в Torst» переводит временный торрент в `persisted`, сохраняя его ID.

Плагин использует ID торрентов и файлов, постраничную загрузку через курсоры и `If-Match` для изменения настроек. Видеопоток доступен по `/api/v1/torrents/{torrent_id}/files/{file_id}/content`. Путь к файловому хранилищу задается на инстансе. Torst хранит прогресс каждого профиля в секундах. Плагин сохраняет позиции, которые сообщает плеер, без оценки по переданным байтам или прошедшему времени.

Для запросов из браузера настройте доступ с домена Lampa, в том числе для загрузки торрент-файлов, постеров и аватаров профилей. Для изменения настроек, хранилища и имен профилей прокси должен передавать заголовок ответа `ETag`. Адрес инстанса должен входить в список разрешенных хостов Torst. Методы PATCH, PUT и DELETE используют браузерный транспорт: HTTP-мост Android поддерживает только GET и POST.

## Возможности

- **Пул инстансов с выбором по задержке**:
  - Добавление и настройка нескольких инстансов Torst.
  - **Автоматический режим**: плагин параллельно проверяет инстансы через `/readyz`, измеряет задержку и направляет запросы на самый быстрый из доступных.
  - **Переключение при сбое**: если активный инстанс перестает отвечать, плагин выбирает следующий доступный инстанс с наименьшей задержкой.
- **Предзагрузка перед просмотром**:
  - Запускает предзагрузку через `POST /api/v1/torrents/{torrent_id}/files/{file_id}/preloads`.
  - Показывает прогресс, объем загруженного буфера и его целевой размер, скорость загрузки и число подключенных пиров.
  - Передает воспроизведение в `Lampa.Player.play()`, когда буфер достигает порога готовности.
- **База Torst в боковом меню**:
  - Добавляет раздел **Torst** с собственным компонентом `torst_torrents`. Раздел TorrServer `mytorrents` работает независимо; в режиме «Всегда Torst» плагин скрывает его.
  - Показывает сохраненные в базе торренты с постерами, метаданными и выбором файлов.
  - Отмечает значком на постере торренты, которые хранятся на диске; показывает число файлов и размер.
- **Профили, прогресс и продолжение просмотра**:
  - Выбирайте, создавайте, переименовывайте и удаляйте профили Torst через кнопку **Профили Torst** в библиотеке или меню действий инстанса. Каждый инстанс запоминает выбранный профиль. В списке видны аватары из Torst; если изображения нет или оно не загружается, появляется стандартный значок.
  - Для выбранного профиля плагин загружает позиции файлов и отметки о завершении из Torst. Если Lampa или внешний плеер сообщает точную позицию, плагин сохраняет ее в этом профиле. Если плеер ничего не сообщает, сохраненный прогресс в Torst не меняется.
  - Прежние позиции просмотра в Lampa сохраняются. У профилей Torst отдельные локальные записи; пункт **Прогресс только в Lampa** возвращает исходные позиции. Плагин не переносит их в Torst автоматически.
  - Кнопка **Продолжить просмотр** в библиотеке открывает список Torst: можно продолжить файл или включить следующую серию. Удаление записи из этого списка не удаляет торрент и его прогресс.
  - После возврата из внешнего плеера фокус возвращается в исходный список или окно выбора файла. Прежняя отметка просмотра на карточке торрента остается локальной в Lampa; Torst хранит завершение просмотра отдельно для каждого файла.
- **Поиск через Jackett и Prowlarr**:
  - Отдельный пул поисковых провайдеров в **Настройки → Torst → Управление провайдерами поиска**.
  - Параллельный поиск через все включенные провайдеры, удаление дубликатов и сортировка по числу сидов.
  - Переключатель **Показывать в общем поиске** в меню **Управление провайдерами поиска** добавляет вкладку **Jackett / Prowlarr** в общий поиск Lampa. На вкладке видны число найденных торрентов и полный список с датой, трекером, числом сидов, размером, качеством, аудиодорожками и субтитрами. Отдельная настройка **База Torst в общем поиске** добавляет вкладку сохраненных торрентов с числом совпадений, карточками и списком файлов, как в библиотеке Torst. При открытии общего поиска из библиотеки Torst эта вкладка выбирается автоматически.
  - Когда включены Torst и хотя бы один провайдер, плагин заменяет стандартный поиск торрентов Lampa. В остальных случаях используется стандартный поиск Lampa, если он доступен. Если стандартного поиска нет, плагин сообщает об ошибке.
- **Выбор способа воспроизведения**:
  - Кнопка **Torst** в карточках фильмов и сериалов.
  - Действия **Смотреть через Torst** и **Сохранить в Torst** в контекстном меню торрента, которое открывается долгим нажатием.
  - Три режима: всегда использовать Torst, спрашивать перед просмотром о выборе Torst или TorrServer, либо запускать Torst только через кнопку и контекстное меню.
- **Тип хранилища и сохранение в базе**:
  - **Оперативная память (`memory`)** или **Диск (`disk`)**. Для хранения на диске нужно сохранение в библиотеке; временный просмотр использует оперативную память.
  - **Всегда** сохраняет торрент в библиотеке Torst, **Никогда** запускает временный просмотр в оперативной памяти.
  - Режим **Спрашивать перед просмотром** позволяет выбирать хранилище и сохранение в базе перед каждым запуском. Выбор можно запомнить.
- **Аутентификация и токены**:
  - Без аутентификации или с паролем Torst (Bearer).
  - **Bearer**: вход с паролем Torst через `POST /api/v1/access-tokens`. Токен доступа действует сутки; плагин обновляет его автоматически. Имя пользователя не требуется.
  - **Токены воспроизведения**: `POST /api/v1/playback-tokens` для видеопотока и постеров.
- **Поддержка ТВ и браузеров**: плагин собирается в самостоятельный JavaScript-файл без внешних зависимостей для Android TV, Tizen, WebOS и браузеров на компьютере.

## Установка в Lampa

1. Откройте **Lampa** на устройстве.
2. Перейдите в **Настройки** → **Расширения**.
3. Нажмите **Добавить плагин**.
4. Введите URL собранного плагина:

   ```text
   https://your-domain.example.com/dist/torst.js
   ```

   Файл `dist/torst.min.js` также можно разместить на своем хостинге, CDN или GitHub Pages.
5. Перезапустите Lampa. Раздел **Torst** появится в **Настройках** и боковом меню.

## Настройка

В Lampa откройте **Настройки** → **Torst**:

| Настройка | Описание | По умолчанию |
|---|---|---|
| **Включить Torst** | Просмотр и поиск торрентов через Torst. При воспроизведении через Torst Lampa пропускает рекламу перед видео | `Включено` |
| **База Torst в общем поиске** | Поиск сохраненных торрентов на активном инстансе через общий поиск Lampa | `Отключено` |
| **Выбор инстанса** | `Авто (наименьшая задержка)` или `Выбор вручную` | `Авто (наименьшая задержка)` |
| **Управление пулом инстансов** | Добавление и редактирование инстансов, учетные данные, проверка задержки и выбор активного инстанса | Меню действий |
| **Управление провайдерами поиска** | Добавление и редактирование провайдеров Jackett и Prowlarr, проверка задержки. Когда Torst и хотя бы один провайдер включены, здесь также доступен переключатель **Показывать в общем поиске**. Он добавляет отдельную вкладку результатов и при первом включении использует настройку общего поиска торрентов из Lampa | Меню действий |
| **Воспроизведение торрентов** | `Всегда Torst`, `Вручную (кнопка и меню)` или `Спрашивать перед просмотром (Torst / TorrServer)` | `Всегда Torst` |
| **Тип хранилища** | `Оперативная память`, `Диск` или `Спрашивать перед просмотром`. Для хранения на диске нужно сохранение в базе; при временном просмотре используется оперативная память | `Оперативная память` |
| **Сохранение в базе** | `Никогда`, `Всегда` или `Спрашивать перед просмотром` | `Никогда` |
| **О плагине** | Версия плагина и информация о сборке | Информация |

## Безопасность и хранение учетных данных

- **Обфускация сохраненных паролей**: перед записью в `Lampa.Storage` (`localStorage` или хранилище WebView) плагин обрабатывает пароли обратимым шифром с префиксом `enc:v1:`. Это скрывает пароли от случайного просмотра хранилища, в том числе при демонстрации экрана или выгрузке его содержимого.

  > [!NOTE]
  > У JavaScript-плагина в браузере или WebView телевизора нет доступа к защищенному аппаратному хранилищу или системному хранилищу ключей. Обфускация затрудняет случайный просмотр пароля, но не защищает от человека с полным доступом к устройству или исходному коду плагина.

- **Токены только в памяти**: токены доступа и токены воспроизведения хранятся в оперативной памяти. Плагин не записывает их на диск или в постоянное хранилище.
- **Общие устройства**: если к хранилищу телевизора или профиля имеют доступ другие плагины и скрипты, защитите само устройство и профиль: сохраненный пароль Torst дает доступ к управлению инстансом.

## Интеграция с Lampa

Плагин передает каждому элементу воспроизведения и плейлиста `Lampa.Player` признак `continue_play: true`, а сам плейлист — до начала просмотра. Lampa пропускает рекламу VAST перед видео, пока такой элемент находится в текущем плейлисте. При переключении серии Lampa очищает плейлист, поэтому Torst восстанавливает его до проверки рекламы для следующей серии. Признак `torrent: true` также передается, но лишь обозначает торрент-воспроизведение.

## Разработка и сборка

### Требования

- [Node.js](https://nodejs.org/) 24.x начиная с 24.18.0 либо 26.4.0 и новее.
- `npm`.
- Google Chrome или Chromium для проверки верстки страницы установки. По умолчанию тесты запускают `google-chrome`; путь к другому исполняемому файлу Chrome или Chromium можно задать через `CHROME_BIN`. Если браузер не найден, тесты верстки пропускаются.

### Установка зависимостей

```bash
npm install
```

### Проверка качества

CSS-свойства следуют порядку RECESS из `stylelint-config-recess-order`. Тесты проверяют таблицы стилей, блоки `<style>` и атрибуты `style`; порядок пользовательских CSS-свойств остается на усмотрение автора.

Тест верстки страницы установки запускает Chrome без графического интерфейса и проверяет выравнивание панели навигации, видимость версии и работу меню на обоих языках, в обоих каналах выпуска, при мобильной и настольной ширине экрана.

Перед коммитом выполните проверки:

```bash
# Запустить тесты
npm test

# Проверить типы TypeScript
npm run typecheck

# Проверить код с ESLint
npm run lint

# Автоматически исправить ошибки оформления
npm run lint:fix

# Собрать файлы для распространения
npm run build
```

Результат сборки:

- `dist/torst.js`: самостоятельная сборка без минификации, с картой исходного кода.
- `dist/torst.min.js`: минифицированная сборка.
- `dist/index.html`: страница установки со ссылками на плагин и документацию.
