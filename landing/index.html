Torrent Streaming for Lampa

A Lampa plugin for playing torrents, with buffering and a multi-instance pool.

Prerequisite

Torst Application Required

This plugin is a client for Lampa. Torrent streaming requires a running, self-hosted Torst application. Set up Torst first, then connect the plugin to it.

Features

Features

Multi-Instance Pool

Pings all Torst instances in parallel, routes to the lowest latency, and fails over if one drops.

Preload Buffering

Buffers torrent stream pieces to a readiness threshold before handing off to the player, with poster art and speed stats.

Library Torrents

Browse saved torrents from the Lampa sidebar, choose individual files, and mark torrents as viewed.

RAM & Disk Storage

Stream in RAM to avoid writing to disk, or use disk storage for large library torrents.

Password Authentication

Password sign-in for API access, with playback tokens for video stream URLs.

TV Remote Support

Native Lampa dialogs, masked password entry, and D-pad navigation on Android TV, Tizen, and WebOS.

Jackett & Prowlarr Search

Searches all enabled providers concurrently, tolerates individual failures, removes duplicates, and sorts by seeder count.

Setup

How to Install in Lampa

  1. 1
    Open Lampa on your TV or device, navigate to Settings → Extensions.
  2. 2
    Click Add Plugin.
  3. 3
    Paste the copied Production URL (torst.min.js) and confirm.
  4. 4
    Restart Lampa. A dedicated Torst entry will appear in Settings and the main sidebar.
